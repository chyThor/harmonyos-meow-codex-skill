# macOS / Linux 配置

当前 `setup` 向导使用 Windows 加密机制。macOS / Linux 需要把接收信息保存为仅当前用户可读的外部 JSON 文件。脚本使用 Python 标准库，但尚未在这两个系统做实机验证。

## 配置

1. 在终端创建私有目录及文件：

   ```sh
   mkdir -p "$HOME/.config/meow-push"
   chmod 700 "$HOME/.config/meow-push"
   (umask 077; touch "$HOME/.config/meow-push/config.json")
   chmod 600 "$HOME/.config/meow-push/config.json"
   ```

2. 用本地文本编辑器打开这个文件，填入以下结构，把两个空字符串替换成自己的信息。不要通过聊天或共享编辑器填写。

   ```json
   {
     "base_url": "",
     "recipient": "",
     "device_label": "我的电脑"
   }
   ```

   `base_url` 是接口基础地址，`recipient` 是 MeoW 的接收标识。配置文件是受文件权限保护的明文，不能随 Skill 或项目一起分享。

3. 设置环境变量，并从同一环境启动 Codex：

   ```sh
   export MEOW_PUSH_CONFIG="$HOME/.config/meow-push/config.json"
   python3 "$HOME/.agents/skills/meow-push/scripts/meow_push.py" status
   ```

   看到 `"configured": true` 表示配置可读取。Codex 执行脚本时也必须能读取这个环境变量；桌面应用不一定继承终端变量，需要按其启动方式配置。解释器使用 `python3`。

随后按[主说明](../README.md)发送测试消息。不要将 `config.json` 放进 Skill 文件夹或 GitHub 仓库。换机器需在该机器重新配置。
